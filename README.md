# Chatbot Project

This is an AI-powered chatbot implemented in Python using **Google Generative AI API** and **ipywidgets**.

## Features
- Interactive chat interface in Google Colab
- Select from multiple AI models
- Clear chat and reset functionality
- Easy to extend for custom responses

## Setup Instructions
1. Open `chatbot project.ipynb` in Google Colab.
2. Replace `"YOUR_API_KEY_HERE"` with your own Google Generative AI API key.
3. Run all cells and start chatting with the bot.

## Notes
- The API key is **not included** for security reasons.
- The notebook uses the `google-generativeai` and `ipywidgets` packages, which are installed at runtime.
